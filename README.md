# Enterprise AI Engineering Knowledge Hub

## Overview
This repository serves as a structured, professional knowledge base and portfolio for advanced AI Engineering, LLM architectures, and Java-based AI system integrations (Spring AI, LangChain4j). It documents theoretical foundations, architectural patterns, and production-grade implementations.

## Roadmap & Core Modules

### Module 1: LLM Foundations & Tokenization
- Subword Tokenization & Byte-Pair Encoding (BPE) mechanics.
- Context windows, attention mechanisms, and prompt engineering patterns.

### Module 2: Java AI Ecosystem & Tool Use
- Enterprise integration using Spring AI and LangChain4j.
- Retrieval-Augmented Generation (RAG) pipelines and Model Context Protocol (MCP) implementations.

### Module 3: High-End Portfolio Projects
- Production-ready applications showcasing autonomous agents and robust AI workflows.
